# 🧮 Calculator Web App

A simple and responsive **Calculator Application** built with **HTML, CSS, and JavaScript**.  
This app allows users to perform **basic arithmetic operations** with a clean and modern UI.

---

## 🚀 Features

- ➕ Addition, ➖ Subtraction, ✖ Multiplication, ➗ Division  
- 🧹 Clear button to reset input  
- 🔙 Backspace functionality  
- ⚡ Instant evaluation using JavaScript `eval()` (or custom logic)  
- 📱 Responsive design – works on desktop and mobile  

---

## 🛠️ Tech Stack

- **HTML5** – structure of the app  
- **CSS3** – styling and layout  
- **JavaScript (Vanilla JS)** – app logic
